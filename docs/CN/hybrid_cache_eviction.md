# Hybrid Attention 快照回收顺序

Hybrid radix cache 同时维护两种近期性：KV 树节点的访问顺序，以及 bounded attention 小页快照的恢复顺序。沿缓存路径做前缀匹配会访问多个节点，但只有最终真正恢复的小页状态才应该被视为使用过。

本改动将小页快照的 LRU 时间从节点访问时间中分离出来：

- 普通树遍历仍更新 `time_id`，不改变 KV 节点回收顺序。
- 只有完成小页状态恢复后才更新 `state_time_id`。
- 新挂接的快照从当前时间进入状态 LRU。
- 删除无引用叶节点后，连续的无状态父节点一并清理，避免只删掉 KV 尾页却保留不可恢复的空壳路径。

这样，当一个更长前缀因为图片边界或显存不足退回大页恢复时，沿途未使用的小页不会被错误地刷新为热门，有限的小页槽位会优先回收真正较旧的快照。
